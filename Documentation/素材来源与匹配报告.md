# 素材来源与匹配报告

## 结论

对用户保留的 Unity Windows 构建与 `RedFF0000/Finite-state-machine` 仓库中的 `Finite-state machine.unitypackage` 进行比对后，确认最终构建使用了参考包中的多组角色、背景和敌人素材。

比对以文件名和尺寸作为候选条件，并以解码后的 RGBA 可见像素相似度作为主要证据。Unity 导入过程会对纹理重新编码或压缩，因此不能只比较 PNG 文件字节。

| 类别 | 确认匹配数量 | 证据 |
|---|---:|---|
| Adventurer 角色独立帧 | 64 | 同名、同尺寸、可见像素相似度 ≥ 98% |
| 多层背景 | 11 | 同名、同尺寸、可见像素相似度 ≥ 98% |
| Skeleton 敌人图集 | 6 | 同名、同尺寸、可见像素相似度 ≥ 98% |
| 动画片段 | 10 个同名候选 | 名称与对应角色素材一致；构建导出后 YAML/GUID 会变化 |
| Animator Controller | 2 个同名候选 | `player.controller`、`Enemy.controller` |

参考包共有 126 张 PNG，其中 45 张没有以同名文件进入最终构建，主要是施法、空中攻击、翻滚、墙滑和攀角等未使用动作。

## 匹配到的动画名称

- 玩家：`Idle`、`run`、`jump`、`fall`。
- 敌人：`Idle`、`Walk`、`React`、`Attack`、`Hit`、`Dead`。
- 控制器：`player.controller`、`Enemy.controller`。

## 可复现方法

仓库保留了只读比对工具 `Tools/compare_reference_assets.py`。它接收两个目录：解包后的 UnityPackage 目录，以及 AssetRipper 导出的 `Assets` 目录。

```powershell
python Tools/compare_reference_assets.py <unitypackage-extracted> <build-export-assets>
```

工具会输出 JSON，包含候选文件、尺寸、字节是否相同、像素是否完全相同以及可见像素相似度。

## 版权与公开仓库处理

- 指定的 GitHub 参考仓库只有一个 UnityPackage，未提供 `LICENSE` 或包内版权说明，因此不能把“公开可下载”等同于“允许再分发”。
- Adventurer 角色可追溯到 rvros 的 Animated Pixel Adventurer；作者允许个人/商业使用和修改，但限制把素材作为另一套图形素材重新分发。
- Skeleton 图集与 Jesse Munguia 的 Skeleton Sprite Pack 的动画集合和文件结构相符；作者页面允许个人/商业项目使用，但明确禁止重新分发素材包。
- 背景层的原始作者和授权目前无法从参考包内可靠确认。

基于上述情况，本公开仓库只上传代码、比对方法和来源说明，不上传 UnityPackage、角色 PNG、Skeleton 图集和背景图片。若后续获得原作者明确授权，可在保留署名与许可文件后补充素材。
